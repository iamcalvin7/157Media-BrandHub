2026 Peak Summer Offer — Design Brief

Overview

This campaign will serve as the main summer promotional visual system for 2026.

The objective is to create a strong, recognisable campaign identity that can live consistently across:

* digital banners
* website placements
* social media
* Facebook post variations
* performance marketing
* remarketing assets
* seasonal campaign updates

The campaign will run throughout the summer period, so the system needs to feel:

* premium
* scalable
* highly adaptable
* instantly recognisable

⸻

Core Creative Direction

The campaign is built around:

* Sicily destination imagery
* ferry boarding-pass inspired offers
* bold summer messaging
* strong readability across all formats

The visual identity should communicate:

* travel
* movement
* summer escape
* ferry journey experience
* seasonal value

The “ticket” treatment should feel inspired by:

* boarding passes
* ferry tickets
* travel documents

Not generic promotional cards.

⸻

Key Creative Principle

One Key Visual. Multiple Adaptations.

The master artwork should not simply be resized into every format.

Each placement must be:

* thoughtfully adapted
* compositionally rebalanced
* rebuilt where needed

The goal is to preserve:

* readability
* hierarchy
* impact
* destination appeal

across every format.

This is especially important for:

* ultra-wide banners
* small mobile placements
* vertical social assets

⸻

Adaptation Philosophy

Small Banner Sizes

Examples:

* 728×90
* 300×100
* 320×100

These should use:

* simplified layouts
* reduced ticket detail
* stronger hierarchy
* fewer competing elements

Avoid shrinking the full visual into the format.

These placements should prioritise:

* headline
* one key offer
* readable pricing
* destination atmosphere

⸻

Medium Formats

Examples:

* 300×250
* 600×300
* 970×250

These can support:

* multiple tickets
* more detailed pricing
* route information
* stronger travel-ticket styling

However:

* readability remains priority
* spacing must remain clean
* avoid overcrowding

⸻

Tall / Vertical Formats

Examples:

* 300×600
* 810×1440
* social adaptations

These should feel more editorial and immersive.

Use:

* vertical storytelling
* stronger image presence
* stacked ticket compositions
* clearer hierarchy between offers

⸻

Large Website Placements

Examples:

* 1520×360
* 1312×442

These are hero placements.

The Sicily photography should feel:

* cinematic
* aspirational
* spacious

The boarding-pass tickets should integrate naturally into the environment without overpowering the destination.

⸻

Ticket System Direction

The ticket system is now moving toward:

Ferry Boarding Pass Style

The tickets should include:

* perforation cues
* barcode elements
* route indicators
* travel-inspired layouts
* ferry iconography
* structured pricing blocks

while still remaining:

* clean
* premium
* modern
* readable at small sizes

⸻

Important

Do not treat this as:

“one artwork resized many times.”

Treat this as:

“one campaign system intelligently adapted for every environment.”

The quality of adaptation is more important than strict consistency of layout.
